User's Manual

A calm, mouse-first guide. You can use the essential workflow without typing on a keyboard.

Open the Learner's Manual Open the app

Start a job

1. Choose a workspace. Select an existing workspace, or choose New workspace → Create My Workspace. You do not need to type a name.
2. Tell the Discovery agent what you need. Choose Speak and talk naturally. Or choose Paste for copied text, or Import .md to select an existing Markdown file. You do not need to write a specification yourself.
3. Review together. The agent asks about one detail at a time and prepares a proposal. Speak, paste, or import more information to refine it.
4. Approve when ready. Review the proposal and select Approve specification. The Python workflow cannot proceed until you explicitly approve.
5. Follow the work. Open Runs, choose a workflow, and launch it. The progress view shows the phases and result.

Need help? Select Take the tour to walk through the app again. For detailed lessons and explanations, open the Learner's Manual.

Provider credentials

Choose Configuration → AI provider setup. Copy a setting from your provider and choose Paste from clipboard beside it. The intake assistant uses LLM_BASE_URL, LLM_MODEL, and (if needed) LLM_API_KEY. Save values to the workspace's gitignored environment file. Never place keys in source code or commit them.

Accessibility notes

  • Voice input depends on browser support and microphone permission. Clipboard and file-picker alternatives are available.
  • Text fields remain available for people who prefer them, but keyboard typing is not required for the main conversation flow.
  • This is an early interface foundation; guided provider setup and desktop packaging are still to come.
